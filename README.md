# 🧪 Rick and Morty - Character Explorer

Proyecto desarrollado para practicar el consumo de APIs y el manejo de estados globales en **React**.

## 🚀 Tecnologías
* **React.js** (Hooks: `useState`, `useEffect`)
* **CSS3** (Diseño responsivo y Flexbox)
* **API:** [The Rick and Morty API](https://rickandmortyapi.com/)

## 🛠️ Funcionalidades
* Renderizado dinámico de tarjetas de personajes.
* Buscador funcional por nombre.
* Consumo de datos asíncronos mediante `fetch`.

## 📦 Cómo ejecutarlo
1. Clona el repo: `git clone https://github.com/Kevin-Arevalo29/rick-and-morty-character-explorer.git`
2. Instala dependencias: `npm install`
3. Corre el proyecto: `npm run dev`
